# CLAUDE.md: fp-skills-free

## What this is

The public, free sample of Fer Patel's video skills: a Claude Code plugin marketplace (`fp-skills-free`) with
one plugin, `fp`, holding `/fp:ui-morph-loop` and `/fp:list`. Free to use; it points people to the paid
library of 44 skills at ferpatel.ai.

## Stack

- **Not a website, no app code of its own.** A plugin marketplace: `.claude-plugin/marketplace.json` lists
  the one plugin, `plugins/fp/` is the plugin (`.claude-plugin/plugin.json`, `skills/list/`,
  `skills/ui-morph-loop/`). No Vercel, no Supabase, no Stripe, no CI workflows.
- Each skill carries its own bundled `engine/` (Node 18+ scripts using Playwright, Python 3 helpers,
  ffmpeg). The engine is MIT; the skills are free for personal use, not for republishing
  (`LICENSE.md` in each skill).

## Environment

No `.env` or `.env.example`, and none needed here. The engine reads optional keys from the user's own
shell at run time, never from this repo (names only, from `plugins/fp/skills/*/engine/scripts/`):

- Optional service keys: `ELEVENLABS_API_KEY` (voice-over), `REPLICATE_API_TOKEN`, `PEXELS_API_KEY`.
- Tuning and path overrides: `ELEVENLABS_BASE`, `REPLICATE_BASE`, `PEXELS_BASE`, `REPLICATE_POLL_SECONDS`,
  `REPLICATE_TIMEOUT`, `CHROME`, `FFMPEG`, `PLAYWRIGHT_BROWSERS_PATH`, `CLAUDE_CONFIG_DIR`.

## How people install it

```
/plugin marketplace add wizardsofsocial/fp-skills-free
/plugin install fp@fp-skills-free
```

Existing installs only update when the version changes, so any content change needs a version bump.

## Conventions specific to this repo

- **This repo is generated. Do not hand-edit it.** Its working copy on Fer's machine is
  `/Users/fer/Documents/Coding Projects/video-skills-socials/dist/fp-skills-free`, inside the git-ignored
  `dist/` of the private `fp-skills` repo (local folder `video-skills-socials`). The files here are the
  output of `node scripts/build-free.mjs` in that repo, which rebuilds the whole tree from `skills/`,
  `engine/`, `guides/` and `release.json` there (run `node scripts/build-guides.mjs` first so the Quick
  Start PDF is included).
- **To change anything:** edit the source in `fp-skills`, bump the skill's version and `freePlugin` in its
  `release.json`, run the two scripts, then commit and push from `dist/fp-skills-free` (steps in that repo's
  README, "The free repo"). A hand edit here is overwritten by the next export.
- **Versions must agree:** `freePlugin` in `release.json` becomes the version in both
  `.claude-plugin/marketplace.json` and `plugins/fp/.claude-plugin/plugin.json` (currently 1.0.3).
- Which skills are free is set by `"free": true` in `release.json` there. Currently only `ui-morph-loop`.
- Local test: in Claude Code, `/plugin marketplace add` with the path to this folder.

## Known landmines

- **Never put the paid skills or private repo content here.** This repo is public; the private `fp-skills`
  repo must stay private. Only skills marked free ship.
- **No version bump, no update:** users on the old version will not receive changes.
- Skills drop their `fp-` prefix here (`ui-morph-loop`, not `fp-ui-morph-loop`) because the plugin name
  supplies it (`/fp:ui-morph-loop`). Do not rename them to match the private repo.
- The Quick Start PDF is a build output (`ui-morph-loop/UI_Morph_Loop_Quick_Start.pdf`) and the README links to it.
