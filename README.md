# Free skills by Fer Patel

> **Skills by Fer Patel** · [ferpatel.ai](https://ferpatel.ai)

Free Claude Code skills that make real videos from code: a page drawn frame by frame and rendered to MP4, with sound,
captions and loudness mastering, checked before it's handed over.

## Install

```
/plugin marketplace add wizardsofsocial/fp-skills-free
/plugin install fp@fp-skills-free
```

Then ask for a video in your own words, or run a skill directly:

| Command | What it makes |
|---|---|
| `/fp:ui-morph-loop` | Makes a 10-20 second seamless looping UI motion video where ONE shape never cuts: it morphs through 8-12 real interface states of a product (button, loader, check, toggle, slider, tabs, chart, command palette, toast) on a beat grid, driven by a cursor with real clicks, drags and typing, then loops back to frame one. |
| `/fp:list` | Lists every Fer Patel skill you have installed |

The first time a skill runs it sets up its engine (Node 18+, ffmpeg and Python 3 needed; it installs Playwright itself).
